# criticality-compass-data

The stored results of Criticality Compass that the `criticality-compass` distribution does not carry, under CC BY 4.0 (`DATA-LICENSE`).
Install it beside `criticality-compass`; the files go into the same `criticality_compass/workspace/results/` directory, so a command that names one of these results works once it is installed.
Without it, such a command refuses with a line that says the result is absent.
