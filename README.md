# Criticality Compass (CC)

CC reads reduced measurements of a statistical model, applies declared relational instruments (Kernel V8
operators over declared relations), and prints, for every point, what was measured and what the rulebook
decides. Cases and the verdict table are data files: you change them by editing TOML, never code.

Status: v0 under construction (plan 0863). Run `bin/cc` for the help text.
